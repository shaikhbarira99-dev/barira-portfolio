BARIRA SHAIKH — PORTFOLIO
=========================
Files:
- index.html: website content and structure
- style.css: design, responsive layout and animations
- script.js: interactions, typing effect, scroll reveals and project modals
- resume/resume.pdf: add your actual resume PDF here

RUN LOCALLY
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Put your actual resume PDF in the resume folder and name it resume.pdf.
4. Right-click index.html and choose "Open with Live Server" (install the VS Code Live Server extension if needed), or open index.html directly in your browser.

BEFORE SUBMITTING
- Confirm your education dates and descriptions are accurate.
- Add your resume PDF.
- Test GitHub and LinkedIn links.
- Be ready to explain the HTML, CSS animations and JavaScript interactions.
Google Fonts needs an internet connection; local fallback fonts are included.
